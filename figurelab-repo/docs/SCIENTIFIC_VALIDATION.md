# Scientific validation checklist

For each quantitative method added to FigureLab:

1. State the scientific purpose and scope.
2. Define required inputs and units.
3. Document equations and assumptions.
4. Identify corrections and optional parameters.
5. Define behaviour for invalid/ambiguous inputs.
6. Create simple analytical test cases where the expected result is known.
7. Compare representative outputs with a trusted independent implementation or reference calculation.
8. Record known limitations.
9. Add regression tests before changing implementation details.
10. Ensure exported methods/provenance contain enough information to reproduce the result.
