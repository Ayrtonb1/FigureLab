# Starter roadmap

## Foundation
- Canonical measurement/data model
- Project and sample model
- Recipe/provenance schema
- Test fixtures and validation strategy

## Technique workflows
- XRD
- FTIR/Raman spectroscopy
- TGA/DSC
- Additional techniques only when user evidence supports them

## Cross-cutting workflows
- Experimental-series comparison
- Reusable processing recipes
- Publication-ready plots and tables
- Exportable methods/provenance record
- Native instrument-file import prioritised from observed user demand

This roadmap is deliberately capability-oriented rather than a commitment to specific scientific algorithms.
